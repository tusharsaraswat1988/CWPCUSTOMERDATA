Task 01.1 Semantic Distinction
Destructive Outlined (Secondary Action)
Class: .cwp-v2-btn-danger
Secondary Emphasis

Used for reversible or lower-consequence destructive actions where user awareness is needed, but the action must not dominate the screen hierarchy.
Examples: "Remove Stop from Route", "Discard Draft", "Detach Vehicle".

Danger Solid (Primary Action Confirmation)
Class: .cwp-v2-btn-danger-solid
High Emphasis

Used exclusively for final, high-consequence confirmation actions inside explicit confirmation modals or dangerous delete dialogs.

Overlay Architectural Standards Verified
  • Focus Management: Pinned to initial inputs or safe Cancel buttons; focus automatically returns to the launching element on dismiss.
  • Tab Focus Trap: Keyboard navigation cycles exclusively within the active overlay boundaries.
  • Stack & Nested Support: Multi-overlay depth tracking prevents z-index clipping and closes only the topmost overlay on ESC.
  • Body Scroll Locking: Automatically prevents background document jitter without layout shifting.
  • Restrained Backdrop: rgba(15, 23, 42, 0.45) slate veil with subtle 2px blur for maximum operational readability.
  • No Frameworks Required: Pure vanilla JS engine strictly namespaced under window.CWP_ADMIN_V2.overlay.

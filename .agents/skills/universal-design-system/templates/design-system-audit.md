# Design System Audit Checklist

Mark each item PASS / FAIL / NOT APPLICABLE / NOT VERIFIED. Include evidence and issue references. Do not mark NOT VERIFIED as PASS.

## Context and governance
- [ ] Product/user/platform context documented
- [ ] Design principles are observable and actionable
- [ ] Source references and applicability are documented
- [ ] Owner, version, contribution and exception process exist

## Foundations
- [ ] Primitive and semantic tokens are separated
- [ ] Color roles and theme mappings documented
- [ ] Text and non-text contrast assessed
- [ ] Typography hierarchy and scaling rules documented
- [ ] Spacing, layout, grids and responsive rules documented
- [ ] Shape, borders, elevation and layering documented
- [ ] Icon/image usage and licensing documented
- [ ] Motion and reduced-motion behavior documented
- [ ] Content/voice/localization conventions documented

## Components and patterns
- [ ] Core component inventory exists
- [ ] Components document purpose, anatomy, variants and states
- [ ] Search/filter behavior documented where relevant
- [ ] Forms, validation and errors documented where relevant
- [ ] Tables/data grids have correct semantics and responsive strategy
- [ ] Navigation, overlays and feedback patterns documented
- [ ] Empty/loading/error/offline/recovery states covered where relevant
- [ ] Critical task journeys are represented by reusable patterns

## Accessibility
- [ ] Target and applicable requirements confirmed
- [ ] Keyboard-only review completed
- [ ] Focus visibility/order/restoration reviewed
- [ ] Accessible names, roles, states and relationships reviewed
- [ ] Screen reader checks completed for critical journeys
- [ ] Contrast, reflow, text resize and target size reviewed
- [ ] Reduced motion/high contrast reviewed where applicable
- [ ] Localization and RTL reviewed where applicable

## Implementation and quality
- [ ] Token source of truth identified
- [ ] Generated outputs reproducible
- [ ] Approved components reused
- [ ] Exceptions documented and approved
- [ ] Responsive/visual review completed at representative sizes
- [ ] Automated tests/checks run and results recorded
- [ ] Known gaps, owner and remediation dates recorded

### 1.3 Verified Gaps in `public/admin-v2/` (Must Be Resolved Before/During Migration)

1. **Zero Responsive Media Queries in `v2-layout.css` (`public/admin-v2/css/v2-layout.css:1–292`):** No `@media` rules exist. `.cwp-v2-sidebar` is fixed at `250px` (`--cwp-v2-sidebar-width`) and `.cwp-v2-app-container` uses `overflow: hidden; width: 100vw`, which clips/squishes `<1024px` viewports. `--cwp-v2-sidebar-width-collapsed: 68px` (`v2-tokens.css:92`) has no matching `.is-collapsed` CSS or JS toggle.
2. **External Google Fonts CDN Dependency (`public/admin-v2/index.html:10–12`):** Loads `Inter`, `JetBrains Mono`, and `Material Symbols Outlined` from `https://fonts.googleapis.com`, violating `docs/design-system/01 §7` (offline/self-hosted WOFF2 requirement) while `public/fonts/material-symbols-outlined.woff2` (4.02 MB) is already bundled in the repo.
3. **Missing `Noto Sans Devanagari` & `line-height: 1.5` (`v2-tokens.css:112`, `v2-base.css:14`):** `--cwp-v2-font-sans` omits `Noto Sans Devanagari`, and `body.cwp-v2-body` sets `line-height: 1.4` (and Task 07 `34px` compact cells need explicit optical padding for Hindi customer names/addresses).
4. **Non-Reusable Playground Coupling (`public/admin-v2/js/v2-playground.js`, 4,296 lines):** Only exports `window.CWP_ADMIN_V2.playground = { init }` (`L4286–4288`). Task 06 (`bindSelectionPlayground`, `L1138–2280`) and Task 07 (`bindTableDataGridPlayground` / `TASK07_OPERATIONS_DATASET`, `L2282–4280`) are IIFEs bound to playground element IDs and 5 hardcoded mock datasets (`MOCK_OPERATIONS`, `SEARCHABLE_SERVICES`, `TASK06_OPERATIONS`, `ZONE_DEFINITIONS`, `TASK07_OPERATIONS_DATASET`).
5. **`v2-auth.js` Session Verification Bug (`public/admin-v2/js/v2-auth.js:42–68`):** `checkSession()` sends `POST /api { action: 'getStaffList', token }`. Because `getStaffList` (`server.js:3013`) is public-optional and returns `HTTP 200` even without a valid admin token, `checkSession()` (`res.ok`) falsely treats any non-empty/expired/bogus `localStorage.cwp_admin_token` as valid (`{ valid: true }`). Also lacks V1's `rememberAdminDevice` `sessionStorage`-only toggle and `logoutAdmin` API revocation call.
6. **Shell Feature & URL Contract Gaps (`public/admin-v2/js/v2-shell.js:1–146`):** Supports only 6 hash views (`ui-lab`, `dashboard`, `customers`, `staff`, `dispatch`, `settings`) via `window.location.hash`. Lacks V1's `?tab=` + `#admin/<tab>` URL contract (`app.js:2668–2691, 3076–3089`), sidebar collapse state persistence (`localStorage.cwp_admin_sidebar_collapsed`), mobile drawer (`#adminSidebarBackdrop`), live SSE stream (`EventSource('/api/admin-realtime-stream')`) + sync popover, EN/HI language switcher, and account/logout modal flow.
7. **Dark Mode Token Gap (`v2-tokens.css:8–303`):** Unlike `m3-tokens.css`, `v2-tokens.css` defines only light workspace tokens (`Locked Decision #11`).

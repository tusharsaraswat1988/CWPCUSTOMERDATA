# CWP SEE-12.4 — Service Specification Gap Audit

## 1. Requirement-to-Implementation Comparison

| Area | Original SEE Specification | Backend Support (`services/seeApiRouter.js`, `seeCatalogueRepo.js`) | Production Admin V2 Status | Classification |
|---|---|---|---|---|
| **Service Identity** | `service_code` (unique, immutable after create), `name`, `service_category_id`, `service_model`, `status` | `POST /api/see/services`, `PATCH /api/see/services/:id` | Implemented in `#v2SeeProdServiceModal` & `#v2SeeProdServicesTableBody` | **IMPLEMENTED, NOT VERIFIED** (syntax & DOM verified; live browser CRUD pending) |
| **Service Content** | `tagline`, `description`, `details`, `name_hi` | Supported on `public.services` (`tagline`, `description`, `details`, `name_hi`) | `tagline`, `description`, `details` restored in Create/Edit & Details; `name_hi` not exposed in UI | **IMPLEMENTED, NOT VERIFIED** (`name_hi` **MISSING** in UI) |
| **Service Media (1:1 & 4:3)** | Independent `square_1_1` & `rectangle_4_3` upload/select, preview, replace, remove | `POST /api/see/media` registers `storageUrl` + `width`/`height` + `altText`; **no multipart binary upload** and **no `DELETE /api/see/media/:id`** | URL + altText + live 1:1 / 4:3 preview + replace via `POST /api/see/media` implemented; binary upload & server-side media removal blocked | **BLOCKED BY BACKEND/API** (binary upload & delete endpoint missing) |
| **Service Tags** | Assign configurable marketing tags (`Recommended`, `Popular`, `New`, `Exclusive`, `Premium`, `Sale`, `Most Affordable`) | `GET /api/see/marketing-tags` & `POST /api/see/marketing-tags/attach` exist; **no detach endpoint** | Loads live tags from API, attaches new tags on save, displays attached tags in Details; detaching persisted tags blocked | **BLOCKED BY BACKEND/API** (tag detach endpoint missing) |
| **Categories** | Dynamic `service_categories` | `POST /api` `getServiceCatalog` returns `SERVICE_CATEGORIES` | Populated dynamically; defaults to non-DCC category (`car_washing`) | **IMPLEMENTED, NOT VERIFIED** |
| **Models & Model Config** | `recurring`, `visit_credit`, `site_quantity`, `one_time`, `flexible_custom` + `execution_config` | `service_model` CHECK + `execution_config` JSONB | Model-specific panel renders only compatible fields (`unit_label`, `requires_quantity_verification`, `default_cadence`, `allow_addons`) | **IMPLEMENTED, NOT VERIFIED** |
| **Checklist** | Add, edit, remove, reorder, empty/duplicate validation | `checklist_requirements` JSONB array | Structured item editor (`#v2SeeProdSvcChkList`) with Add, inline Edit, Move Up/Down, Remove, empty/duplicate checks | **IMPLEMENTED, NOT VERIFIED** |
| **Duration** | Positive integer minutes | `expected_duration_minutes INTEGER CHECK (> 0)` | Validated `1–1440` integer minutes | **IMPLEMENTED, NOT VERIFIED** |
| **Photo Proof** | Enable/disable, `before_min`, `after_min`, conditional visibility | `photo_requirements` JSONB | Toggle hides/shows `before_min`/`after_min`; validates `before_min + after_min >= 1` when enabled | **IMPLEMENTED, NOT VERIFIED** |
| **City / Zone Applicability** | All cities/zones vs specific cities/zones | `city_zone_applicability` JSONB; **no `/api/see/cities` or `/api/see/zones` endpoint** | Structured `.cwp-v2-filter-chip` selector hydrated from `getAllRoutes`; dedicated `cities`/`zones` master API missing | **BLOCKED BY BACKEND/API** (dedicated `/api/see/cities` & `/api/see/zones` endpoints missing; using `getAllRoutes` interim) |
| **Add-on Compatibility** | Service-level eligibility + `addon_service_applicability` | `execution_config.allow_addons` + `addon_service_applicability` (managed by Add-ons) | Labeled clearly as Service-level eligibility flag; Details drawer shows `applicableAddons` read-only | **IMPLEMENTED, NOT VERIFIED** |
| **Versioning** | Increment `service_versions` on update | `updateService` increments `version` & inserts `service_versions` | Edit displays next version & optional `reason` | **IMPLEMENTED, NOT VERIFIED** |
| **Lifecycle** | `draft`, `active`, `retired` with confirmation | `POST /api/see/services/:id/status` | Retire confirmation modal (`#v2SeeProdServiceConfirm`); `Edit`/`Retire` disabled on `retired` | **IMPLEMENTED, NOT VERIFIED** |
| **Details Drawer** | Full parity with persisted fields | `GET /api/see/services/:idOrCode` | Displays identity, category/model, tagline/description/details, 1:1 & 4:3 images, checklist, duration, proof, scope, tags, add-ons, version/status | **IMPLEMENTED, NOT VERIFIED** |
| **DCC Isolation** | DCC isolated from generic SEE creation & route workflows | `daily_car_cleaning` category & `SVC-DCC*` | Create blocks `daily_car_cleaning` / `SVC-DCC*`; Edit locks `service_model` to `recurring`; DCC routes untouched | **IMPLEMENTED, NOT VERIFIED** |
